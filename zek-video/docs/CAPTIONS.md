# Instagram captions

One per reel. Each ends with the same primary action so the DM keyword stays
consistent across the set.

**A note that applies to all three:** while the reels use placeholder graphics
instead of real property media, none of these captions should be posted as-is —
they describe work the imagery does not yet show. Swap in real footage first
(see `SWAPPING-MEDIA.md`), then post. The captions are written and ready for
that moment.

## What these captions deliberately do not say

No price. No turnaround time. No revision count. No number of clients, views,
bookings or enquiries. No testimonial. No "guaranteed reach" — "might" in the
follow line is doing real work and must not become a promise about what
Instagram will show anyone.

Reel 03's comparison is presented as an editorial demonstration about craft. It
is not a claim that a particular opening shot produces more bookings.
